# ☕ Coffee Shop Game - Unity Project

## Установка

1. Скачайте и установите [Unity Hub](https://unity.com/download)
2. В Unity Hub установите версию Unity (рекомендуется 2022 LTS или новее)
3. Откройте Unity Hub → New Project → 2D Core → Create

## Настройка проекта

### 1. Импорт скриптов
Скопируйте все `.cs` файлы из папки `Assets/Scripts` в вашу Unity-проекцию:
- `Assets/Scripts/Coffee.cs` - базовый класс кофе
- `Assets/Scripts/GameManager.cs` - управление игрой
- `Assets/Scripts/Customer.cs` - клиенты и заказы
- `Assets/Scripts/CoffeeMaker.cs` - станция приготовления
- `Assets/Scripts/CoffeeUI.cs` - интерфейс кофейни

### 2. Создание сцены

**Main Camera:**
- Position: (0, 0, -10)
- Размер камеры: 8

**Создайте объекты:**

1. **GameManager** (Empty GameObject)
   - Добавьте компонент `GameManager`
   - Перетащите ссылки на UI элементы

2. **CustomerPanel** (Empty GameObject)
   - Добавьте компонент `Customer`
   - Создайте дочерние UI элементы:
     - `orderText` (Text) - текст заказа
     - `customerSprite` (Image) - спрайт клиента
     - `patienceBar` (Slider) - полоска терпения

3. **CoffeeStation** (Empty GameObject)
   - Добавьте компонент `CoffeeShopUI`
   - Создайте кнопки:
     - `espressoShotButton` - кнопка эспрессо
     - `hotWaterButton` - кнопка вода
     - `milkButton` - кнопка молоко
     - `frothButton` - кнопка пена
     - `serveButton` - кнопка подать

4. **UI Canvas**
   - Text: Score (Очки)
   - Text: Customer Count (Обслужено)

### 3. Настройка UI

**Кнопки приготовления:**
- Эспрессо: коричневый цвет (#6F4E37)
- Вода: голубой (#87CEEB)
- Молоко: белый (#F5F5DC)
- Пена: светло-бежевый (#FFF8DC)

**Палитра цветов:**
- Фон: тёмно-коричневый (#2C1810)
- Стены: бежевый (#D2B48C)
- Прилавок: коричневый (#8B4513)

## Как играть

1. Клиент подходит и делает заказ (Эспрессо/Американо/Латте)
2. Нажимайте кнопки для приготовления:
   - **Эспрессо** = 1 порция эспрессо
   - **Американо** = 1 эспрессо + 1 вода
   - **Латте** = 1 эспрессо + 1 молоко + 1 пена
3. Нажмите "Подать" чтобы обслужить клиента
4. Правильный заказ = очки
5. Клиенты уходят, если терпение закончилось
6. Обслужите 10 клиентов для победы!
